# 🎯 He, She, or It? — Pronoun Game

Интерактивная игра для учеников 3 класса (A1) на отработку английских местоимений: **I, you, he, she, it, we, they**.

## ✨ Возможности
- 🗂️ **40 заданий** в пуле: 20 картинок-эмодзи + 20 предложений с пропуском
- 🎲 Каждый раунд — 10 случайных вопросов (легко настроить: 10 / 20 / 40)
- 🇷🇺 Подсказки на русском — для A1-уровня
- 🔊 Звуковая обратная связь + произношение правильного ответа (SpeechSynthesis)
- ⭐ Подсчёт очков и звёзд в финале
- 📱 Адаптивно для телефона, планшета и компьютера
- 🌐 Работает офлайн после загрузки
- 🧩 Один файл — легко редактировать

## 🎛️ Настройки
Длину раунда меняет одна строка в `<script>`:
```js
const TOTAL = 10;   // 10 — короткий, 20 — средний, 40 — все вопросы
